# Komponenten-Quellen und Lizenzen

Matrix `Komponente | Pfad/URL | Lizenz | übernommen | Anpassung | Einbauort | Zustände | Nachweis`. Gepflegt von den Paketen der Runde 11; dieses
Dokument wurde mit dem Paket A5 „Interaktionen“ angelegt, andere Pakete ergänzen ihre Zeilen darunter.

Regel: Erst die vorhandene Lösung der App (`src/motion`, `src/primitives`, die Skills unter `neue-dateien/.claude/skills`) prüfen, dann externe Muster.
Von außen wird nur **Idee und Struktur** übernommen, im eigenen Token-System (Federn `spring.*`, Farben, `useReducedFx`) nachgebaut; **kein Fremdcode, keine neue
Abhängigkeit**. Wo unten „kein Code übernommen“ steht, hat das Paket die Seite / das Muster nur als Anregung benutzt – ohne Lizenzfolge.
