# Abdeckung F01–F74

Eine Zeile je Punkt des Bauplans (`Trading-Assistent – vollständiger Bauplan, 74 Punkte`), geprüft gegen den Code dieses Branches. Status:
**fertig** = die Funktion tut, was der Bauplan-Punkt verlangt (Grenzen stehen in der letzten Spalte), **teilweise** = ein benannter Teil
existiert, **fehlt** = es gibt nichts Entsprechendes (die nächste Berührung ist als Pfad genannt). Keine Zeile wird nach Wunsch beschönigt.
Pfade sind relativ zu `trading-journal/`. Der Test `tests/unit/features.registry.test.ts` prüft, dass jede F-ID genau einmal vorkommt, jeder genannte
Pfad existiert und das Funktionsregister (`src/app/features.ts`) keine F-ID mit Status „fehlt“ aufführt. Die Seite „Funktionen“ zeigt dieselben Stände.

Verwendete Quellen der Daten: Binance öffentliche REST/WebSocket-Daten (keine Zugangsdaten), das Journal im lokalen Speicher (optional mit Cloud-Sync über
Supabase), Stripe, Anthropic (nur optional und nur serverseitig). Zahlen kommen überall aus deterministischen Funktionen.
