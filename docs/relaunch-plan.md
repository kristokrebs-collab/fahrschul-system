## 3. DREI PLÄNE

### PLAN A — „DIE LINIE"
> Die Krebs-Kontur ist die Straße.

Das Logo ist eine durchgehende Linie. Diese Linie **entfaltet** sich: Krebs → Fahrbahnmarkierung → Straße im Video → am Ende rollt sie sich zurück zum Krebs.

- **Akt 1** Schwarze Bühne, Krebs zeichnet sich als eine Linie (2,5 s)
- **Akt 2** Die Kontur *streckt* sich zur Fahrbahnmarkierung
- **Akt 3** Markierung wird zur echten Straße im Frame-Scrub
- Die Linie bleibt als Fortschrittslinie über die ganze Seite
- Finale: Linie rollt sich zum Markenzeichen zusammen

**Bewertung** · Kreativität 9/10 · Merkfähigkeit 9/10 · Machbarkeit 6/10 · Seltenheit 10/10
**Stärke:** Nutzt das, was Krebs wirklich einzigartig macht — einen Krebs als Linie hat keine andere Fahrschule.
**Risiko:** SVG-Morph von Krebs-Kontur zu gerader Linie ist technisch anspruchsvoll (unterschiedliche Punktzahlen). Braucht einen bewusst gezeichneten Zwischenpfad.

---

### PLAN B — „DAS OBJEKT"
> Die Referenz 1:1 auf Fahrzeuge übertragen.

Ein Fahrzeugdetail (Scheinwerfer/Felge) als Held, Makro-Push-in genau wie die Uhr.

- Hero: Krebs-Linie → löst sich in die Objektkarte auf → Scrub fährt **in** den Scheinwerfer
- Jede Fahrzeugklasse bekommt ihr eigenes Makro-Objekt
- Frame-Counter + Mono-Labels wie in der Referenz

**Bewertung** · Kreativität 5/10 · Merkfähigkeit 6/10 · Machbarkeit 9/10 · Seltenheit 4/10
**Stärke:** Höchste Planbarkeit — ich habe die Referenzframes, das Ergebnis ist vorhersagbar.
**Schwäche:** Es *ist* die Referenz. Austauschbar — dieselbe Formel funktioniert für Uhren, Saucen, Eistee. Verletzt „einzigartig".

---

### PLAN C — „EINE NACHT"
> Die Seite ist eine durchgehende Fahrt von Nacht zu Morgen.

Der Scrub ist **eine einzige Fahrt**, die über den Scroll von Nacht in den Sonnenaufgang läuft. Jedes Kapitel ist eine Station dieser Fahrt.

- Start: Dunkelheit, nasser Asphalt, rotes Rücklicht
- Mitte: Dämmerung — Simulator, Cockpit
- Ende: Tageslicht = Führerschein = Freiheit
- Rot wandert vom Rücklicht über Statusanzeige zur Ziellinie

**Bewertung** · Kreativität 8/10 · Merkfähigkeit 7/10 · Machbarkeit 8/10 · Seltenheit 7/10
**Stärke:** Erfüllt als einziger Plan die Vorgabe „dunkle UND helle Kapitel" (durchgehend Fast-Schwarz ist laut Briefing verboten). Emotional korrekt: Fahrausbildung *ist* der Weg zur Selbstständigkeit.

## 4. EMPFEHLUNG — Synthese statt Kompromiss

Die drei Pläne konkurrieren nicht, sie bedienen **drei verschiedene Ebenen**. Das Beste jeder Ebene:

> ## „EINE LINIE. EINE NACHT. EIN MORGEN."

| Ebene | Gewählt aus | Warum |
|---|---|---|
| **Signature** | Plan A — die Krebs-Linie | Das einzig wirklich Unverwechselbare. Keine Fahrschule hat das. |
| **Dramaturgie** | Plan C — Nacht → Morgen | Erfüllt Hell/Dunkel-Pflicht, emotional richtig |
| **Motor** | Plan B — Hero Scrub #12213 | Bewährte Mechanik, Originalcode liegt vor |

**Konkret:** Die Krebs-Linie zeichnet sich auf Schwarz, streckt sich zur Fahrbahnmarkierung, und **diese Markierung ist die Straße im ersten Frame** des Scrubs. Der Scrub ist eine Nachtfahrt. Über die Seite hellt die Bühne auf. Im Finale rollt sich die Linie zum Krebs zusammen — jetzt im Morgenlicht.

Ein Element (die Linie), eine Bewegung (der Scrub), eine Reise (Nacht→Morgen).

## 5. TECHNISCHE BASIS (steht bereits fest)

Aus dem Originalcode von #12213 — diese Werte werden **unverändert** übernommen:

```
PIN_VH_MULTIPLE      3.2      → Sektionshöhe 420vh
IMMERSE_OVERFILL     1.04
ENTRY_DELAY          0.2
CARD_START_SCALE     0.6 Desktop / 0.82 Mobil
ScrollTrigger        start "top top", end "bottom bottom", scrub 0.4
Frame-Mapping        clamp(0,1,(p-0.15)/0.63)
Phase 1  0    →0.15  Karte scale→1, Titel ±60vw (mobil ±70vw)
Phase 2  0.15 →0.78  Karte →immerseScale, Titel opacity→0
Phase 3  0.78 →1.0   Karte →startScale, Titel zurück
Laden               20 initial, dann Batches à 20 alle 80ms
Fallback            5 Fehler oder 4500ms → statisches Poster
```
Portierung React→Vanilla: JSX→DOM, Tailwind→CSS, GSAP bleibt (inline eingebettet).
