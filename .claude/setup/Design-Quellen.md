# Design-Plattformen aus Deiner Liste: was ich getan habe (2026-10-25)

Die Seiten selbst sind aus der Cloud-Umgebung nicht erreichbar (Netzwerk-Richtlinie); GitHub und npm gehen. Deshalb nur Offenes von GitHub.

| Plattform | Stand | Wo im Repo / was Du tun kannst |
|---|---|---|
| Magic UI | MIT, geklont und gelesen | Offizielles Skill `magic-ui` (React/shadcn) + 8 Effekte als Vanilla in `pulse-motion/assets/magic-primitives.html` |
| Uiverse | MIT, Archiv geklont | Skill `uiverse-lookup`; Klon auf Deinem Rechner: `.claude/setup/setup-claude-extras.sh uiverse` |
| Aceternity UI | Seite gesperrt, Lizenz nicht geprüft | nichts kopiert. Auf Deinem Rechner prüfen, ob Du den Code nutzen darfst, dann per `npx shadcn@latest add` (laut deren Doku) |
| Refero, Godly | gesperrt; Sammlungen urheberrechtlich geschützter Designs | nur als Inspiration ansehen; Muster in Worten notieren, nicht nachbauen |
| v0, Bolt, Lovable, Flowstep | Dienste, kein Quellcode zum Ziehen | Ablauf: UI dort prompten, Code exportieren, in Claude Code verfeinern lassen |

Wenn Du Aceternity & Co. trotzdem lesen lassen willst: Domains in der Umgebung freigeben (Edit → Network access → Allowed domains, evtl. neue Sitzung) und mir Bescheid geben. Vorher klären wir die Lizenz.
